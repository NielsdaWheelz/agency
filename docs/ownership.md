# ownership

this document defines ownership and review expectations.

## roles

- maintainer: final decision maker, owns release and security.
- reviewer: domain expert for a subsystem.
- contributor: proposes changes and writes tests.

## ownership map

- default owner: maintainer
- subsystem owners: TODO

## review rules

1. breaking changes require maintainer approval.
2. contract changes require updates to `docs/contracts/*` and tests.
3. security-sensitive changes require explicit review notes.
