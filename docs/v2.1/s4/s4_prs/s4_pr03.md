# PR-03: Bounded Stream-Ingestion Hardening for Oversized Runner Lines

## Goal

Close the remaining stream-ingestion safety gap by enforcing a true per-line hard cap before full line allocation, while preserving invocation continuity and normalized-stream ordering guarantees.

## Builds On

PR-02 merged state.

## Acceptance

- Runner stdout ingestion no longer depends on unbounded full-line reads for newline-delimited output.
- Oversized lines are handled deterministically without unbounded memory growth risk: raw output remains preserved, normalized stream emits bounded parse/error signaling, and parsing continues without terminating invocation lifecycle solely because a line exceeds the cap.
- Subsequent valid lines after an oversized line continue to be parsed and written normally.
- Parse/error signaling for oversized input remains machine-usable and consistent with existing stream event semantics.
- Normalized stream event sequencing remains strictly monotonic across append flows, including restart-in-place and legacy reachable start paths after the reader change.

## Non-Goals

- No runner capability target-set or alias behavior changes.
- No mutation-command `--json` envelope or failure-shape changes (`agent start/stop/kill/land/discard/chat/restart`).
- No expansion of semantic-adapter coverage or runner-specific semantic parsing behavior.
- No invocation-scoped review/PR/merge behavior changes (Slice S5 scope).

## Key Decisions (if any beyond L2)

**Oversized-line handling contract**: Lines over the hard cap are treated as non-parseable input for normalized events (with explicit bounded error signaling) rather than partially parsed/truncated semantic events.

**Safety over enrichment**: The parser prioritizes bounded ingestion and continuity guarantees over best-effort semantic extraction for oversized lines.

**Failure posture**: Oversized-line parse handling is fail-open (continue ingestion with explicit signaling), while raw/normalized stream persistence failures remain fail-closed operation failures.
