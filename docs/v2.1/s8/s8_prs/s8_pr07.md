# PR-07: Codex Manual Closure and Output Fidelity

## Goal

Close the remaining Codex-specific S8 gaps so Codex invocations are fully trustworthy across capture, replay, and all human-facing read surfaces.

## Builds On

Slice S8 merged baseline and the manual validation evidence in `docs/v2.1/s8/s8_manual_validation_20260319.md`.

## Observed Failure

- Manual invocation `20260319073701-1b5e` preserved only `sleep-end` in raw/stream tool payloads for a command that printed both `sleep-start` and `sleep-end`.
- The same invocation showed the shared `agent diff --turn` mismatch: `show`, `review`, and `checkpoint ls` reported a changed file and checkpoint, while `agent diff --turn stream:18` printed `(no changes)`.

## Acceptance

- Codex raw and normalized logs preserve complete small command outputs; the manual shell probe from `docs/v2.1/s8/manual_prompts/seed_short.txt` or `seed_live.txt` must retain both `sleep-start` and `sleep-end` in replayable artifacts.
- `agency agent history`, `agency agent history --json`, `agency agent show --json`, `agency agent review`, and `agency checkpoint ls --invocation` converge on the same latest assistant turn, checkpoint id, changed path list, and status for Codex invocations.
- `agency agent diff --turn <latest_turn>` for a Codex invocation shows the file change associated with the checkpoint surfaced by `show` / `review` / `checkpoint ls`; it must not report `(no changes)` when the other surfaces report a changed file.
- `agency agent restart --history` uses the same Codex turn/checkpoint grouping that `agent history` exposes and remains legible with command + file-change heavy turns.
- After `agency agent discard`, the following still work for Codex invocations without a live sandbox dependency:
  - `agent show --json`
  - `agent history`
  - `agent history --json`
  - `agent logs`
  - `agent logs --kind stream`
  - `agent logs --kind stderr`
  - `checkpoint ls --invocation`

## Manual Validation

1. Build the branch binary from repo root:
   - `GOCACHE=/tmp/agency-gocache go build -o ./agency ./cmd/agency`
2. Use a clean integration worktree, then start a Codex invocation:
   - `./agency agent start --worktree <wt> --headless --runner codex --name s8-manual-codex --prompt-file docs/v2.1/s8/manual_prompts/seed_live.txt --json`
3. While it is running, inspect:
   - `./agency agent show <id> --json`
   - `./agency agent history <id>`
   - `./agency agent history --json <id>`
   - `./agency agent logs <id> --follow`
   - `./agency watch`
   - `./agency agent chat <id> --prompt-file docs/v2.1/s8/manual_prompts/followup_live.txt --json`
4. After it completes, inspect:
   - `./agency agent history --last <id>`
   - `./agency agent history --json --last <id>`
   - `./agency checkpoint ls --invocation <id>`
   - `./agency agent review <id>`
   - `./agency agent diff <id> --turn <latest_turn_id>`
   - `./agency agent restart <id> --history`
5. Discard and verify retention:
   - `./agency agent discard <id> --json`
   - re-run `show`, `history`, `logs`, `logs --kind stream`, `logs --kind stderr`, and `checkpoint ls`

## Non-Goals

- No Claude or Cursor lifecycle/parser changes in this PR except shared code required to make Codex surfaces correct.
- No new TUI redesign beyond what is necessary to keep Codex history/restart parity correct.

## Key Decisions

**Codex log fidelity outranks summarization convenience**: raw/stream capture must keep complete tool payloads for small outputs even if higher-level surfaces still summarize by default.

**Codex closure includes replay parity**: a Codex fix is not done when raw capture looks right but `history`, `review`, `checkpoint ls`, and `diff --turn` still disagree.
