# PR-06: Shared Human Renderer and TUI Cleanup

## Goal

Finish the slice by consolidating human-readable rendering and TUI presentation around the shared projections, with concise defaults and explicit raw expansion.

## Builds On

PR-05 merged shared latest-activity and invocation-summary projections.

## Acceptance

- Invocation-facing history and activity surfaces use shared human-readable rendering primitives instead of bespoke formatting paths.
- Default rendering hides full raw tool payloads behind raw, json, or explicit expansion behavior rather than dumping them inline.
- Interactive history and watch experiences use the same projection language and style conventions instead of presenting unrelated visual vocabularies.
- Stylistic improvements do not change the underlying machine-readable or raw-debug contracts.

## Non-Goals

- No new runner-family support beyond Claude, Codex, and Cursor.
- No GUI or web dashboard scope.
- No replacement of raw-debug surfaces with TUI-only access patterns.

## Key Decisions (if any beyond L2)

**Presentation follows data convergence**: this PR assumes the capture, normalization, and projection work is already stable, so visual cleanup remains a consumer of shared truth rather than another source of behavioral drift.
