# PR-03: Canonical Turns and History or Restart Convergence

## Goal

Make `agent history` and `agent restart --history` consume the same derived turn model with concise default human rendering.

## Builds On

PR-02 merged canonical runner event model.

## Acceptance

- `agent history` and `agent restart --history` agree on turn boundaries, prompt or follow-up handling, checkpoint association, and latest meaningful turn behavior for the same invocation.
- Default human history rendering is concise for large tool payloads and large file-edit activity instead of dumping raw detail by default.
- A raw or machine-readable escape hatch still exposes complete underlying output without losing fidelity.
- `agent history --last` resolves to the latest meaningful activity or turn rather than an arbitrary low-level timeline entry.
- Previously misleading prompt-as-tool-result behavior is eliminated for supported runner outputs.

## Non-Goals

- No migration of watch, list, show, review, or diff surfaces in this PR.
- No broad TUI style redesign beyond keeping restart-history aligned with the shared turn model.

## Key Decisions (if any beyond L2)

**Turns, not flat timeline entries, own the default human history contract**: this PR makes meaningful turns the unit of human-default history behavior, while raw timeline detail remains available as an explicit lower-level mode.
