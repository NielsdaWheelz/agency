# PR-05: Live Activity Surface Convergence

## Goal

Make invocation list, watch, show, and review surfaces reuse one latest-activity and status-summary model.

## Builds On

PR-04 merged turn and checkpoint convergence.

## Acceptance

- `agent ls`, `agent ls --watch`, `agency watch`, `agent show`, and `agent review` or `checks` agree on latest activity, display status, summary text, and navigation context for the same invocation.
- Fleet-style surfaces remain additive human views and do not create a new authority path for invocation truth.
- Latest activity shown in list, watch, show, and review surfaces is derived from the same projection model as invocation-local history.
- Raw log reading remains available as a separate debug lane rather than becoming the default list or watch presentation.

## Non-Goals

- No final visual or thematic redesign of the TUI family.
- No expansion of watch actions beyond what current canonical command contracts already support.

## Key Decisions (if any beyond L2)

**Activity summaries are shared projections**: list, watch, show, and review surfaces should summarize invocation state from the same derived model rather than each inventing its own latest-message or latest-tool heuristics.
